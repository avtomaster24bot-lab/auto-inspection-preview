# АвтоМастер24 / Трейд-ин — статическое демо

Это **учебный публичный предпросмотр** интерфейса независимого осмотра автомобиля.

- Нет сервера, базы данных, авторизации и общих медиа.
- Тексты осмотра живут в `localStorage` этого браузера.
- Фото и видео категорий сохраняются в IndexedDB этого браузера (`am24-tradein-demo-media-v1`) и не отправляются на сервер.
- Не вводите реальные данные клиентов, VIN, госномера и файлы настоящего осмотра.
- Кнопка WhatsApp открывает `wa.me` с текстом; сообщение само не отправляется.
- Печать / PDF — через диалог печати браузера, не серверный экспорт.
- Выбор роли в шапке — учебная симуляция, не настоящая система прав доступа.
- Полный Next.js-сервис остаётся в отдельном закрытом репозитории и здесь не публикуется.

Рабочая страница после публикации GitHub Pages:

`https://avtomaster24bot-lab.github.io/auto-inspection-preview/`

Локально: откройте `index.html` через любой статический сервер или напрямую в браузере с поддержкой ES-модулей.

Каталог показывает только карточки автомобилей (общая оценка, «Открыть папку», WhatsApp). Семь направлений, описание категории, папки «Фото» и «Видео» открываются после выбора автомобиля. Дальше — оценочный лист или папка направления.

Каждый учебный автомобиль — отдельная папка внутри сайта, не на диске компьютера. Описание, фото и видео привязаны к автомобилю и направлению (`carId/directionId`). Без выбранного файла папки честно пустые: «Пока нет фотографий / видео в этой папке».

Лимиты локальных файлов: фото JPEG, PNG или WebP до 10 МБ, не больше 20 в папке направления; видео MP4, WebM или QuickTime до 80 МБ, не больше 5 в папке. Если место в браузере закончится, появится сообщение о квоте.
