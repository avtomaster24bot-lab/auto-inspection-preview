# Схемы разделов осмотра

Готовые технические фотографии и чертежи из Wikimedia Commons (и уже принятые патентные виды кузова из `../schemes/`). Это не самодельные «лодки» и не заводские карты конкретного демо-автомобиля «ПримерМарка». Подпись на странице всегда называет реальный образец и лицензию.

Файлы уменьшены по длинной стороне примерно до 1600–2000 px, обрезаны по краям кадра без растяжения. Цветные отметки дефектов на сами файлы не наносятся: их рисует интерфейс поверх изображения.

Кузов и вид сверху для положения колёс используют уже принятые патентные чертежи из `../schemes/` (Camry / Outback / Evoque).

Ограничения, о которых сказано на странице:

- Салон показан боковым разрезом реального седана, а не видом сверху: точного свободно лицензированного плана салона сверху не найдено.
- Электрика — силовая схема электромобиля с контуром кузова, а не жгут, АКБ и генератор конкретного ДВС-авто.
- Геометрия сочетает реальную несущую платформу Tesla Model S и принципиальную схему несущего кузова; это не заводской чертёж лонжеронов демо-авто.
- Кузов демо-авто вымышленный, поэтому схемы — образцы соответствующей анатомии, а не сервисная карта конкретной машины.

`electric-layout.png` и `wheels-tire.png` — растр официального превью Wikimedia с исходного SVG; лицензия та же, что у файла на Commons.
