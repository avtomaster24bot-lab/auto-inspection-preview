# Учебные иллюстрации

Файлы в этой папке созданы для публичного демо АвтоМастер24 / Трейд-ин. Это сгенерированные студийные иллюстрации, а не фотографии реальных осмотров и не чужие отчётные снимки.

| Файл | Назначение |
| --- | --- |
| `dir-hodovaya.webp` | Подвеска: пружина и амортизатор |
| `dir-engine.webp` | Двигатель |
| `dir-electric.webp` | Аккумулятор и проводка |
| `dir-body.webp` | Кузов автомобиля |
| `dir-interior.webp` | Передние сиденья и панель |
| `dir-geometry.webp` | Рама и лонжероны |
| `dir-wheels.webp` | Колесо и протектор |
| `car-sedan.webp` | Учебная иллюстрация седана (тот же ракурс, что кузов) |
| `car-wagon.webp` | Учебная иллюстрация универсала |
| `car-crossover.webp` | Учебная иллюстрация кроссовера |
