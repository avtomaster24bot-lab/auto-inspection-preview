Готовые ортогональные чертежи из опубликованных патентов США на промышленный образец. Это не самодельные контуры и не схема конкретного демо-автомобиля «ПримерМарка». Подпись на странице всегда называет реальную модель-образец.

Файлы получены обрезкой и поворотом на 90° без искажения пропорций, затем уменьшены до длинной стороны 2400 px. Фон белый, подписи фигур патента убраны. Повреждения на чертежи не наносились.
